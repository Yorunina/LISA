# LISA 第一版运行仪表盘需求

更新：2026 年 10 月 28 日。状态：D26 范围已确认，B16 待开发。本轮交付需求，不代表代码、运行配置或服务已变更。

## 目标与范围

维护者能够判断 LISA 是否正常运行、任务为何等待或失败、各用途模型调用量与费用如何变化，以及 RAG 在索引、检索和上下文装入的哪个阶段丢失信息。首版覆盖运行状态、任务处理、模型调用、费用、RAG 五方面，复用现有网页、数据库和后台任务，不新增独立监控服务。

产品规则以[项目方案](PROJECT_PLAN.md#运行仪表盘)及[公众试用与预算](PROJECT_PLAN.md#公众试用与预算)为准；本页维护首版指标口径、页面行为和验收规格。工程归属见 [B16](DEVELOPMENT_TASKS.md#b16-第一版运行仪表盘与消费额度调整)。

## 消费额度调整

普通聊天及其他文本生成取消应用内每日金额、单任务金额、按用户或用途分配的金额额度，以及作为消费配额的调用次数上限。覆盖聊天、主动话题、作者、角色、日记、周表、记忆整理、蒸馏、试聊/试写、复核和重试。原平台每日 10 元上限及“今日额度耗尽”暂停行为退出现行需求；不通过设定极大金额模拟无限额。D25 图片链路继续无消费额度。

费用统计与执行许可分离：价格缺失、usage 缺失、历史估算高于旧额度、跨日或旧在途预留都不得阻断新的文本生成；必要的查询向量和个人索引也不再被原平台日额/任务金额连带阻断。取消额度不免除供应商实际收费，也不消除其余额不足或限流等错误。

保留输入与上下文长度、单次输出长度、明确的任务范围、有限阶段与重试、运行并发、超时、取消、停用、账号及角色权限、作品顺序、联系频率、24 小时自主暂停和累计自主推进边界。review 的一次草稿及一次复核仍是两阶段流程；去掉消费次数拦截不增加第三次改写或循环生成。token/字符预算表示请求容量，不表示消费余额。

本轮不扩大取消额度的范围到独立的共有表情视觉/公共向量维护：D20 原独立每日 1 元维护上限保留，不再包含于已取消的 10 元总额；它不得阻断普通聊天、文本整理或其他文本生成。图片已有规则仍按 D25。历史金额与调用记录保留，不回写为零或重新解释为免费。

## 访问与页面

仪表盘是仅维护者可访问的独立只读入口，不加入普通用户的创作主流程，不授予维护者阅读私人聊天、作品或完整提示词的权限。使用现有登录并由部署配置明确指定维护账号；普通登录用户和未登录请求都不能读取监控接口，不通过隐藏菜单代替后端鉴权。不建设角色管理后台。

页面采用现有“私人书房”样式，包含总览，以及任务、调用与费用、RAG 的详情区域。总览显示组件状态、待处理任务、异常、调用量、费用完整性和最近一次 RAG 评测；支持从统计进入对应的脱敏记录。首版不提供重启服务、修改密钥、恢复任务、重试未知请求或调整消费额度的按钮。

时间范围提供今日、近 7 日、近 30 日和自定义区间；按用途、模型、任务类型、调用状态筛选。采用明确显示的部署统计时区，默认 Asia/Shanghai；时间戳存储沿用现有 UTC。使用统一的左闭右开区间，日/月趋势按该时区分桶，不沿用旧预算重置日充当本地自然日。

支持手动刷新；自动刷新间隔可配置，建议 30 秒。页面显示采集/刷新时间和数据起始时间；过期、断连、加载失败和无数据明确区分，失败时可保留上次数据但标明过期。窄屏可阅读，图表需配数值和文字状态，颜色不作为唯一依据。

## 运行与任务指标

| 范围 | 首版展示 | 口径与解释 |
| --- | --- | --- |
| API 与数据库 | 当前可达状态、最近检查时间、API 错误与耗时 | 现有 health 只证明 API/数据库可用，不推出 worker、QQ 或模型正常 |
| 后台执行 | 普通 worker、图片 worker、QQ gateway 的心跳及过期状态 | 按实际承担职责记录，多个队列可由同一进程处理；不要求另起进程 |
| QQ | 网关连接/登录状态、最近收发时间、待发送、失败及未知投递 | 没有新消息不等于离线；网关成功不等于用户已读 |
| 任务队列 | 当前可执行等待数、运行数、最老等待时长、未来计划数 | 未来计划、10 秒合批等待、实际可执行积压分别统计，正常等待不标为故障 |
| 任务结果 | 所选期间完成、失败、取消、结果未知数量及原因 | 任务完成、正文采用和 QQ 送达分开，不以模型返回成功代替业务完成 |
| 等待与处理 | 排队耗时、执行耗时、聊天端到端耗时的中位数/P95 | 聊天明确显示是否包含静默合批、排队、生成及投递；部分/未知投递单列，不静默排除失败 |

当前队列数量是刷新时刻的快照，不随历史区间假装恢复过去的队列。历史任务按创建时间统计流入，按结束时间统计结果，页面明确标注；成功率采用同一批已结束任务作分母，不能用同一时段的流入数除以流出数。进行中项不计入完成率，等待最长项与超时项仍需可见。

## 模型调用与用途

每项请求记录关联任务及调用尝试，区分任务来源与实际调用用途。一个聊天任务可能同时包含查询向量、视觉和回复生成，不能全部归为聊天文本费。

| 用途分组 | 至少覆盖的明细 |
| --- | --- |
| 交流 | 正常聊天、主动话题、试聊、复核 |
| 创作 | 作者生成、角色参与、必要修改/检查、日记 |
| 计划与记忆 | 周表、记忆或设定整理 |
| 风格 | 蒸馏观察、合成、验证、试写及纠正 |
| 图片 | 视觉理解、绘图描述准备、实际生图 |
| 向量 | 资料索引、查询向量，个人与共有来源可分辨 |
| 平台维护与评测 | 共有表情分析/整理、RAG 评测；继续标明实际文本/视觉/向量类型 |

首版显示每类的请求次数、成功/失败/结果未知、输入输出 token、耗时中位数/P95、估算费用和费用未知次数；可按模型及安全的供应商别名细分。未知用途单列，不丢弃，也不根据当前配置猜测历史用途。

任务数、调用尝试数与实际请求数分别表达。等待并发名额、取消前未发送、本地输入校验失败不算供应商请求；现有 reserved 台账不足以证明已发出。实现需记录发送阶段；若发送与落库之间异常而无法确认，则列为“发送待确认”，不强行归零。SDK/系统重试的每次外部尝试均需纳入，重启恢复不能重复计数同一次尝试。

模型返回成功、结构校验成功、业务采用成功分别表达。错误至少区分连接/超时、HTTP/限流、输出截断、结构或业务校验失败、取消及外部结果未知。供应商调用可在业务取消后成功并产生费用，不能从消费统计中删除。

调用趋势按发起时间归属；成功率分母为同一批已结束且确认发送的调用，成功、失败和结果未知均显示，进行中与发送待确认单列。耗时分位数标明样本量及覆盖的终态；token 缺失显示未知，不补成零。

## 费用与账单

统一人民币，不作汇率换算；历史 `*_usd` 名称不作为界面币种依据。每条调用保留当时的模型、价格版本与计价依据，价格调整不追溯覆盖历史估算。

页面同时显示所选期间的费用趋势、按用途/模型的分摊、每任务平均与明细，以及以下互斥的金额来源：

- **供应商已返回或已核对金额**：标明来源；首版可没有账单接入，此时显示未接入。
- **应用估算金额**：按当时已知 token 和单价计算，与实际账单分开。
- **保守待确认金额**：缺少 usage 或外部结果未知时沿用的旧预留/保守结算，不能混成已确认账单。
- **无法计价调用**：显示数量与类型，不计成免费；图片 usage 全零也不能单独证明免费。

可加总金额仅展示“当前可计价合计”，同时给出上述分项及费用未知数量；存在未知时明确说明总体费用不完整。同一调用得到更可靠金额时替换其计价来源，不把估算与实际重复相加。在途预留另列，不与已结束消费重复计入。

费用按调用发起时间分桶；供应商账单若采用不同入账时间或日界，核对时展示差异。历史记录缺少用途、usage 或费用来源时显示覆盖率和未知，不伪造完整历史。账号删除继续遵守现有删除边界；保留的无身份汇总不能恢复个人明细，页面需说明汇总与可查明细的覆盖差异。

## RAG 线上运行

按聊天、作者、角色分别统计，个人资料与共有表情检索分开。每次检索的状态包括未启用、无可检索资料、已执行、降级、失败和结果为空，不能把未执行全部记作空召回。

| 指标 | 定义与用途 |
| --- | --- |
| 有效索引覆盖 | 当前有效、允许对应用途且应建索引的来源中，版本和向量空间均匹配且索引完整的来源数 / 总来源数；显示未建、过期、失败、部分完成数量 |
| 检索耗时 | 查询向量、数据库检索、组装分别计时；无样本不填零 |
| 候选与装入 | 检索阶段候选数、去重后数、最终进入模型上下文的来源数与字符数；按来源/条目去重，不以重复切片充数 |
| 空结果率 | 实际执行后无有效结果的次数 / 实际执行次数；同时显示无资料、检索关闭等未执行次数 |
| 降级 | 向量失败、近期记忆兜底、标题匹配等路径的次数与原因；兜底成功不能被记成语义召回成功 |
| 省略与失效 | 因上下文字符预算、请求总大小、数量上限、版本变更而省略的条目数与原因；权限过滤与账号/用途范围单独表达 |

采集覆盖“有效索引 → 候选检索 → 组装 → 最终请求”阶段；已有来源引用不等于最终确实进入请求，更不等于模型采用。没有真实证据时不得显示“回答使用率”。跨账号、跨作品及角色知识越界另作隔离回归，不以提高召回率为由放宽权限。

## RAG 固定评测

首版准备约 30—50 个经人工核对的测试问题，覆盖聊天记忆、作者设定/当前正文、角色知识。使用合成或明确允许的材料，不默认复制私人聊天；每题指定账号/作品/用途、资料版本、允许范围和应找到的来源或完整条目。与应用运行态隔离，评测不写入真实记忆、采用正文或发送 QQ。

| 指标 | 计算方式 |
| --- | --- |
| Recall@K | 前 K 个去重候选中的目标来源/条目数 / 本题应找到的目标总数 |
| Precision@K | 前 K 个实际返回的去重候选中相关项数 / 实际返回项数；不足 K 时同时显示实际数量；相关标注不足时不报精确值 |
| 最终上下文覆盖率 | 最终模型请求中完整保留的目标来源/条目数 / 本题应找到的目标总数 |
| 无答案与范围排除 | 不应召回的题单列，检查是否混入禁止来源；不将空目标的 Recall@K 计算为 100% |

按题计算后展示宏平均及每个用途的分数、题数、失败题和省略原因。没有返回候选时，有目标题的 recall 与覆盖为 0，precision 标明无返回；无目标题不参与召回均值。来源/条目的标注粒度固定，不用片段分子除以文档分母。若需语义判断信息是否被回答采用，后续另评，不混进首版确定性指标。

K、字符预算、来源快照、向量模型/空间、检索代码版本、评测集版本和运行日期均随结果保存。模型或资料变更后，旧分数标为历史；不同配置不可只展示为一条连续提升曲线。首版以基线及回归差异为依据，不凭空规定通用达标分数；小型样本不声称代表所有真实请求。

优先在检索改动后运行，支持部署配置安排低频评测；首版至少交付可重复执行的命令及结果读取，不要求在页面上运行模型。线上采集不增加逐轮模型评分；评测产生的向量/模型调用单独计入用途与费用，评测异常不能阻断聊天。

## 异常提示

首版在页面内集中显示组件心跳过期、QQ 断连、持续积压/长任务、调用错误上升、未知请求、索引积压及费用记录不完整。阈值属于可配置运行参数，实施时依据正常时延设置并在界面解释；10 秒静默合批和未来计划不计为异常积压。

单次偶发失败与持续故障区分；同类异常合并，恢复后显示已恢复及时间。成本突然增长仅提示，不暂停调用；供应商余额或限流错误如实显示。首版不新增外部告警渠道，不通过主动 QQ 联系用户报告运维信息。

## 数据与实施边界

复用 ModelCall、Task、OutboundMessage、IndexState、IndexChunk 及已有来源引用。补充用途、发送阶段、worker/gateway 心跳、检索阶段计数和评测结果所缺的最少字段；不以一行台账代表已具备完整请求追踪。

默认采集状态、计数、时间、长度、来源 ID/版本和安全错误码，不记录聊天或检索 query 原文、作品正文、记忆内容、完整提示词、密钥和供应商完整异常正文。运维记录不成为第二套聊天历史；账号删除清除可关联明细，评测报告不得夹带个人原文。

监控读取分页、限定区间；历史统计可按日聚合。采集及聚合失败不阻断模型主链路，但必须暴露数据过期或采集缺口；不要吞掉既有任务/调用本身必须持久化的错误。保留周期与聚合策略作为部署参数，实施交接写明实际取值及清理方式，不无限积累逐轮诊断明细。

不纳入首版：完整分布式追踪、独立日志搜索平台、CPU/GPU 全面运维、大规模自动评审、逐回复 LLM 评分、供应商账单爬取、自动扩容/重启、支付或用户套餐，以及以监控名义恢复消费限制。

## 验收标准

| 编号 | 场景与通过标准 |
| --- | --- |
| A01 | 未登录/普通用户直接访问页面和 API 均不能读取监控；维护者只能看到脱敏运维数据 |
| A02 | 数据库正常但 worker 停止、QQ 离线、心跳过期分别可见；无消息和采集失败不被伪装成在线或零值 |
| A03 | 未来计划、10 秒合批、并发等待、执行、已结束任务分开统计；积压时间正确，取消不计为成功 |
| A04 | 同任务含聊天/查询向量/视觉或作者/角色时用途分摊正确；实际外部重试逐次统计，纯等待不增加请求数；恢复不重复计数 |
| A05 | 成功、HTTP 错误、超时/未知、输出截断、结构失败、业务未采用及投递失败可区分；token 缺失不填零 |
| A06 | 金额已核对、估算、保守待确认和无法计价互斥；图片无价格、usage 全零不显示免费；实际覆盖估算不重复累计 |
| A07 | 本地自然日跨 UTC 日期的趋势正确，近 7/30 日及自定义区间筛选一致；分位数/百分比带样本量，空样本无虚假成功率 |
| A08 | 索引旧版本、向量空间改变、索引不完整、无资料与关闭检索分别可见；降级、标题命中和语义检索分开 |
| A09 | 已检索到的长记忆因字符预算整条省略时，候选 recall 与最终覆盖不同；后续请求装箱丢弃也可定位，重复片段不抬高分数 |
| A10 | 固定评测在同一快照/配置可重跑；无答案题、越权资料、不同用途和角色范围正确处理；旧配置分数不冒充当前效果 |
| A11 | 所有文本用途在旧日账超过 10 元、旧任务金额/次数达限、缺价格、缺 usage、跨日、重试及在途恢复下仍不因消费配额被阻断；必要向量不被旧总额连带阻断 |
| A12 | 去掉消费拦截后，并发、超时、有限阶段/重试、取消、未知不盲重发、账号删除、24 小时自主暂停、联系设置及作品顺序仍生效；无自动补跑或无限生成 |
| A13 | 页面不再以余额耗尽禁用文本生成或显示“今日服务额度已用尽”；供应商余额不足等真实错误仍可辨认；D25 无额度、D20 独立非文本维护边界正确 |
