### 关键缺陷与复核

真实题Q11162询问是否接定制，R1却纠缠陌生称呼，没有回答接不接，导致关键满足9/10。它仍会因不熟悉专名而错过整句话的用意；部分讽刺会被当成客服诊断，普通分享也偶尔转成重复追问。
