# 前端设计原型

返回 [文档入口](../README.md)。


用浏览器直接打开 `.docs/prototype/index.html` 即可，无需安装依赖。采用暖纸色、墨绿、宋体正文与书封元素，围绕作品阅读组织页面。该美术方向已确认（D11），后续实际开发按 [前端美术与界面规范](../FRONTEND_DESIGN.md) 执行。点击左下角“关于这间书房”或顶部信息图标，可查看配色、字体、设计意图与原型边界。

可以体验正文编辑保存、章节切换、专注阅读、版本恢复、世界设定编辑、角色 prompt 编辑、检索配置、记忆搜索／纠正／用途开关，以及示例正文导出。原型仍含旧版的结局比较、主线标记与分叉说明，这些已被 D05 的首版裁剪取代，仅作为历史演示保留，正式工作台不实现。原型任务弹窗中“采用与通知仍待 D04 细化”的说明，以及账号、删除记忆弹窗中完整导出和备份仍待 D10 确认的说明均已过期，现行规则见 [项目方案](../PROJECT_PLAN.md)。AI 重写和 QQ 绑定没有接入服务；原型尚未覆盖新确认的使用前初始化及 LISA 性格选择与设计页面。全部示例数据仅存于页面内存，刷新后重置；请勿用于保存真实创作。

需要 HTTP 预览时，在项目根目录运行 `python -m http.server 8765 --bind 127.0.0.1 --directory .docs/prototype`，然后访问 `http://127.0.0.1:8765`。原型源码为 HTML、CSS、JavaScript；这不决定正式应用框架。示例人物、作品和便笺不构成 LISA 初始人格的确认，D01 至 D10 的状态按 [决策索引](../DECISION_LOG.md#决策索引) 处理，不受本次美术确认改变。
