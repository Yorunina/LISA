# 直接聊天 prompt 优化实验

2026 年 10 月 27 日用户要求暂不采用蒸馏，改为助手直接编写prompt、用golden set测试，争取得到显著有效的版本。本轮只做离线产物和有界真实模型实验，不应用到生产配置，也不删除已有蒸馏能力。

候选A使用口语交流原则，候选B增加新编少量示例。两者都在新确认集生成前固定，不含golden set参考答复、测试题或按题号定制的答案。对照为此前实际使用的无蒸馏基线：现行通用交流约定与LISA基础指引。候选替换整段实验用系统prompt，不再附加蒸馏卡片或运行场景分类。

开发题固定为D01、D03、D04、W01、W03、W05。每候选与同批新生成的基线比较，按用户参考优先标准评分，选择自然度表现较好且事实/求助没有明显回退的版本。允许最多一次根据开发结果修改；不能利用确认题输出调参。

选定后冻结prompt，完整跑14题已知golden set作为开发回归。由于这些题此前已被查看和使用，不将它们声称为未见留出。另用12个新编、预先固定的确认情境，每题每臂独立生成2次；题目覆盖分享、吐槽、分歧、具体求助、语气转折、边界、身份、告别、详细解答、纠错和不确定性。参考、预期和评分规则仅给评审，生成仅接收prompt与该臂会话。

确认集预先采用以下判据，不能看完结果后放宽：

- 至少11/12个情境和22/24对输出可评分；缺测不当作质量零分，也不自动重试未知请求。
- 以情境为独立单位，对每题两次生成的自然度分差取均值；整体改善至少0.5/4，按情境重采样的95%bootstrap下限大于0，情境级双侧符号检验p<0.05。
- 第一轮生成的全部12题交换a/b重评，偏好一致率至少75%；评分只有同模型证据，不能代替独立人类验证。
- 具体求助、详细说明、纠错与未知事实等关键行为单列，候选不能通过漏答、永远一句话或虚构事实来获取自然度分数；关键要求满足率不低于基线且至少90%。

随机种子只固定顺序，不固定供应商生成。若未达到判据，如实交付最佳候选与失败证据，不不断试题直到p值通过。新确认集由助手编写，属于合成确认，不能外推真人长期自然度。
