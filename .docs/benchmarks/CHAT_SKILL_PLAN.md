## 质量与判据

- 自然度 0—4：具体、平等、顺口、合乎当前语境；短答、段子、温暖、礼貌或口头禅均不单独加分。空泛复述、客服澄清、惯性追问、过度指导与宣布策略作为具体缺陷。必要长答正常评分。
- 事实可靠性与明确任务单列；无依据的肯定和否定对称处理。新增身份/地点/经历/操作成功，以及把推测当机制事实，都须核对；明显比喻不按字面误判。引用上下文或角色设定、虚拟生活采用规则与常识性条件推断分别判断。
- 每对匿名评审，两题一批；确认的所有真实题交换顺序复评。增加否定事实评审校准，保留原自动分数及逐条人工式 AI 复核差异；无独立真人评分时明确标注。
- 预定“高分且比 C 稳定改善”：新真实题完整评分至少26/28、至少18个episode；自然度均分≥3.5/4；episode配对均差≥0.3、簇bootstrap95%下限>0、簇双侧符号检验p<0.05；交换偏好一致≥75%；真实关键要求不低于C、事实虚构不多于C；8项合成行为探针全部实质通过。所有门槛在确认前固定；失败后不改门槛、追加题目或在同题继续优化冒充确认。
- 如仅得到高绝对分、未超过C，或出现小样本不确定性，如实交付最佳已测候选与边界，不宣称任务效果已被充分证明。
