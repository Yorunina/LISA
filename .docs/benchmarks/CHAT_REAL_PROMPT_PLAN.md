主问题是R相对C是否有增量，不把弱基线对照冒充超过C的证据。预先确认完整“显著改善”需同时满足：

- 至少22/24题、16/18时段簇有评分；缺测不当零分，不重放未知调用。
- 按时段簇的自然度均差≥0.3/4，4000次簇bootstrap95%下限>0，簇级双侧符号检验p<0.05。
- 全24题C/R答案交换顺序复评，至少20题有结果且偏好一致≥75%。
- 4道guard全部完成且R实质要求全过；真实关键题R要求满足率不低于C，R事实虚构不多于C。布尔标记不稳定或明显错误时，原标记保留并作保守定性复核，不凭单一总数宣称能力无回退。
- 校准通过。原通用基线对照为次要描述，不用于替代上述门槛；不将两次对照中更有利的p值充当主结果。
