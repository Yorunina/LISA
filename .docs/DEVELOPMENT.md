## 正式应用运行

在项目根目录执行；凭据仍读取本地 `.env`，新配置项参见 [.env.example](../.env.example)。

```powershell
# 数据库服务；保留既有数据
.\scripts\dev.ps1 Start

# 应用迁移与队列表初始化，可重复执行
.venv\Scripts\python.exe -m lisa migrate

# 发放一次性邀请，明文只在此输出。初批总共最多 20 个，包含已使用名额。
.venv\Scripts\python.exe -m lisa invite --count 1

# 构建网页后由同一个 API 进程提供 http://127.0.0.1:8000
npm.cmd run build
.venv\Scripts\python.exe -m uvicorn lisa.app:create_app --factory --host 127.0.0.1 --port 8000 --no-access-log

# 另一个终端运行 worker；消费聊天、作者与索引队列，配置有效时会调用模型
.venv\Scripts\python.exe -m lisa.worker
# 处理当前可执行任务后退出；不是无副作用的环境探针
.venv\Scripts\python.exe -m lisa.worker --once
```

需要外网模型访问的长期 worker，应在正常终端或经授权的沙箱外启动，保留本机既有代理配置。已实测受限沙箱中的后台进程会获得拒绝连接的代理地址，不能用一次前台探针成功推断后台 worker 可联网；遇到此类限制应使用授权的运行环境，不通过清空或绕过代理配置规避限制。

## 开发模型配置与小样本验证

模型字段定义于 [settings.py](../lisa/settings.py)，模板见 [.env.example](../.env.example)。当前候选为 `gpt-6-astra`，通过 `https://test.mcii.cc/v1` 兼容接口调用；密钥仅保存在本地 `.env`。开发默认限额为每天 US$0.50、每任务 US$0.15，按 UTC 零点重置；并发 1、对话输出上限 600 tokens、超时 60 秒、同任务最多 3 次调用。作者默认每次正文最多 600 字符、输出上限 1,200 tokens，使用相同每日/任务预算，不另开写作额度。输入/输出每百万 token 的估算参数为 US$10/US$50，**仅用于开发预算预留，不代表已核实的供应商账单价格或正式 D09 配置**。

每次请求先落库预留预算与并发位置；SDK 自动重试关闭。仅 `reserved` 调用占用本地并发；`unknown` 保留估算费用并禁止同一任务继续请求，用户之后的新任务仍可按剩余预算执行，不因历史未知结果永久阻塞。关闭 HTTP 重定向后，确定发生在连接前的 `ConnectError`、`ConnectTimeout`、`PoolTimeout` 记为 `failed`、估算费用为零；其他结果不明的错误继续保守处理。日志只记录异常类型、errno/winerror 与调用关联号，不记录密钥、请求或完整异常文本。

开发输入上限为序列化请求的 11,000 UTF-8 字节，只从最旧历史开始裁剪，完整保留人格与当前消息批次；仍超限时固定提示缩短人格或分段发送，不截断当前要求后调用。队列只按业务明确抛出的 `JobRetry` 重试，不自动重跑意外异常或未知模型请求。网页阅读和手动保存不依赖模型额度。需要重新做少量实测时，使用已有测试账号并明确传入 `--live`；该命令会产生实际调用与费用，不属于常规测试套件：

```powershell
.venv\Scripts\python.exe -m scripts.probe_model --live --user existing-test-account --turns 2
# 两次合成写作/改新约束重写；不创建个人作品或发送 QQ
.venv\Scripts\python.exe -m scripts.probe_writing --live --user existing-test-account
```

探针必须从项目根目录按模块运行；直接执行 `scripts/probe_model.py` 或 `scripts/probe_writing.py` 会因模块搜索路径缺少项目根而导入失败。探针任务与用量保存在实际数据库，合成输入/输出记录位于忽略的 `runtime/`，不应提交到仓库。

启用后每分钟由 Procrastinate 扫描到期计划，计划尚未到时不会创建待执行作者任务，因此不挡网页手动生成。到期及实际开始前分别检查当前作品、共识、24 小时活跃期、未理解消息、累计次数与已有任务；模型调用继续经过原费用台账。新 QQ 事件先使旧计划与未开始的自主任务失效，重复投递不触发；新消息理解完成后才可能重新规划。旧消息保留可信时间，不借接收时间刷新活跃或补跑旧计划。

```powershell
# 本命令只排队；运行中的 worker 消费任务时才产生向量调用及费用
.venv\Scripts\python.exe -m lisa index
```

索引记忆、世界书/角色资料/偏好/暂定方案与各章当前正文；稳定人格、有效约束及当前摘要由调用方直接提供。原始聊天与历史正文不进入本轮向量索引。每批最多 32 个片段、合计 32,000 UTF-8 字节，长资料在已完成批次之后继续排队。保存立即使旧修订切片不可召回，新向量不阻塞保存；片段只保存来源、版本、位置和向量，不保留原文副本。用途、账号、作品和当前版本在相似度排序之前过滤，记忆纠正后的日记来源排除沿用生活时间线规则。

索引、查询向量和文本生成共用日额度、任务额度、调用次数与并发限制。索引日额度不足时将原任务延至下一个 UTC 日；繁忙只延期原任务；单任务额度耗尽、明确失败及结果未知保留记录，同一来源修订不自动重建失败任务。修改来源或切换向量模型空间会产生新的索引需求。更换模型/地址/维度立即排除旧空间向量。

聊天和作者有可用索引时才请求查询向量，默认召回最多 5 个片段、合计 1,500 字符，另受完整请求 11,000 UTF-8 字节上限约束；可选检索资料超限时舍弃，引用记录随实际组装保留来源、修订与范围。没有有效索引时仍直接读取允许用途的有效记忆。查询期间记忆被修改或删除会停止本次生成，不将旧记忆继续传给模型。检索参数和引用查看界面留 M08-04/B07；本轮不改变生成期间正文编辑的既有边界。

## 日常使用

在项目根目录的 PowerShell 中执行：

```powershell
# 启动数据库；首次创建数据库、pgvector 与 Procrastinate 表
.\scripts\dev.ps1 Start

# 数据库、向量、中文数据与实际 worker 执行检查
.\scripts\dev.ps1 Check

# 启动 NapCat（独立开关，默认后台运行）
.\scripts\dev.ps1 StartQQ

# 登录后只读检查 OneBot 版本和登录状态，不发送消息
.\scripts\dev.ps1 CheckQQ

# 停止服务，保留数据库与会话数据
.\scripts\dev.ps1 StopQQ
.\scripts\dev.ps1 Stop
```

启动数据库通常不需要管理员权限。受限沙箱可能阻止 Windows 令牌创建、本机 TCP 连接或浏览器启动，需要在普通终端或经授权的沙箱外执行；不要为此关闭数据库认证。当前没有注册开机自启动服务，电脑重启后需要执行 `Start`、`StartQQ`。

| 连接 | 地址／配置 |
| --- | --- |
| PostgreSQL | `127.0.0.1:55432`，数据库 `lisa`，普通角色 `lisa` |
| OneBot 正向 WebSocket | `ws://127.0.0.1:3001`；请求头 `Authorization: Bearer <LISA_ONEBOT_TOKEN>` |
| NapCat WebUI | `http://127.0.0.1:6099/webui`；令牌为 `.env` 的 `LISA_NAPCAT_WEBUI_TOKEN` |

密码与两个不同的令牌由 `init` 随机生成，只保存在本地 `.env` 与 NapCat 运行配置中。数据库超级用户为 `postgres`，应用使用非超级用户 `lisa`。本地服务仅监听回环地址，不需要添加公网防火墙放行规则。

`Start` 会保留已有数据，`init` 不覆盖现有 `.env` 和 NapCat 配置。修改数据库密码不能只改 `.env`，还须同步数据库角色；修改 OneBot／WebUI 令牌须同步 `runtime/napcat/config/` 中的实际配置，必要时也检查 NapCat 创建的账号专属配置。数据库端口由 `.env` 控制；QQ 端口当前固定为上述开发端口，若调整须同步配置与客户端。

## NapCat 登录与数据

首次运行 `StartQQ` 后，在 WebUI 扫码登录；也可打开 `runtime/napcat/cache/qrcode.png`。二维码会过期，以运行中的 WebUI 为准。已有账号登录后，可在本地 `.env` 填写 `LISA_QQ_ACCOUNT`，脚本下次启动用 `-q` 选择该账号进行快速登录；会话失效时仍需重新扫码，不能保证永久免登录。
